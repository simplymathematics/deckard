# Refactor Plan (Summary)

This is a summary of the current refactor plan. For the full, up-to-date plan, see the [GitHub repository](https://github.com/simplymathematics/deckard/tree/refactor-squashed).

## Goals

- Canonical config sources in `examples/*/configs`
- Dynamic Hydra ConfigStore registration
- Standardized naming conventions
- Decoupled plugins/frameworks from core
- MyST-native Google-style docstrings for all public APIs
- Strict attribute visibility boundaries
- Adapter contract enforcement


See the [full plan](../../.github/refactor_plan.md) for details and progress tracking (or view in the GitHub repository).
